# Mini Web Projects 🚀  

This repository contains simple web-based projects built using **HTML, CSS, and JavaScript**. These projects are beginner-friendly and help in understanding basic front-end concepts like DOM manipulation, event handling, and local storage.

---

## 📁 Projects Included  

### 1️⃣ **Simple Calculator**
A basic calculator that supports:  
- Addition ➕  
- Subtraction ➖  
- Multiplication ✖️  
- Division ➗  
- Clear display  

📄 Files:
- `calculator.html`
- `calculator.css`

🛠️ Features:
- User-friendly UI  
- Clickable buttons  
- Live display update  
- Uses JavaScript `eval()` for calculation  

---

### 2️⃣ **Bat Ball Stump Game (Basic Version)**
A simple game similar to Rock-Paper-Scissors but with cricket elements.

📄 File:
- `CricketGame.html`

🛠️ Features:
- Random computer choice  
- Result displayed via alert  
- Three choices: Bat, Ball, Stump  

---

### 3️⃣ **Bat Ball Stump Game (Updated Version)**
An improved version with score tracking.

📄 File:
- `Upadte game.html`

🛠️ Features:
- Tracks Wins, Losses, and Ties  
- Uses `localStorage` to save score  
- Displays result on the webpage  
- Reset score option
